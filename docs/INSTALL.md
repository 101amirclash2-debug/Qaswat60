# 📲 دليل التثبيت والتشغيل — «تجارة»

## 1) تثبيت APK على أندرويد (الطريقة الأسهل)

1. حمّل **`Tijara.apk`** من جذر المستودع، أو من صفحة **Releases → «تجارة — أحدث APK»** في GitHub.
2. انقله للهاتف (كابل، واتساب، درايف، أو افتح `http://<IP>:5173/Tijara.apk` من متصفح الهاتف إذا كان الخادم يعمل على نفس الشبكة).
3. اضغط على الملف. إن ظهر تنبيه:
   * أندرويد 8+: **الإعدادات ← السماح بالتثبيت من هذا المصدر** ← رجوع ← تثبيت.
   * أندرويد 7 وما قبل: **الإعدادات ← الأمان ← مصادر غير معروفة ← تفعيل**.
4. اضغط **تثبيت** ثم **فتح**. اسم التطبيق «تجارة» بأيقونة ذهبية على خلفية زمردية.
5. امنح إذن **المايك** فقط إن أردت المحادثة الصوتية في غرف الشبكة (اختياري؛ اللعبة كاملة بدونه).

**المواصفات:** أندرويد 5.0 (API 21) فأعلى · يعمل دون إنترنت تماماً · موقّع بـ v1+v2 بمفتاح ثابت، لذا تُثبّت التحديثات فوق النسخة القديمة دون حذف · الشاشة عمودية · لا إعلانات ولا تتبّع.

> لا يحتاج التطبيق أي خادم أو حساب: كل الأوراق والأرصدة والسجل محفوظة على الجهاز (`localStorage` داخل WebView).

---

## 2) التشغيل كصفحة ويب (للتجربة السريعة على الحاسوب)

```bash
node server/server.mjs
# ثم افتح: http://localhost:5173
```

الخادم بلا أي تبعيات (Node 18+)، ويقدّم الواجهة وغرف WebSocket على نفس المنفذ. أو افتح الملف المستقل **`Tijara.html`** مباشرة بالنقر المزدوج — يعمل بلا خادم وبلا إنترنت.

---

## 3) بناء APK بنفسك

### المتطلبات
| الأداة | الإصدار |
| --- | --- |
| Node.js | 18+ (للتحزيم والاختبارات) |
| JDK | 17 (`java`, `javac`, `keytool`) |
| Android SDK | `platforms;android-34` + `build-tools;34.0.0` (`aapt`, `d8`, `zipalign`, `apksigner`) |
| openssl | لتوليد المفتاح (مولّد مسبقاً في المستودع) |

```bash
export ANDROID_HOME=/path/to/android-sdk     # أو ANDROID_SDK_ROOT
npm ci
npm test                 # 19 اختبار قواعد + اختبار واجهة
npm run build:single     # → Tijara.html  (CSS/JS/Aيقونة مُضمّنة)
npm run build:apk        # → Tijara.apk   (حوالي 20 ثانية، بلا Gradle)
```

خطوات البناء الداخلية: `javac` يترجم `MainActivity.java` مقابل `android.jar` ← `d8` يولّد `classes.dex` ← `aapt` يحزم `AndroidManifest.xml` والموارد و`assets/www/index.html` ← إضافة `classes.dex` ← `zipalign` ← `apksigner` بتوقيع v1+v2.

**أو بدون أي أدوات محلية:** ادفع التغييرات إلى الفرع، وسينفّذ `GitHub Actions` سير عمل `Build تجارة APK` تلقائياً: اختبارات ← بناء ← تحقق (`apksigner verify`, `aapt dump badging`) ← رفع الـ artifact وإرفاقه بإصدار `tijara-apk-latest`. حمّله من صفحة الـ run أو من Releases.

### إعادة توليد الأصول الاختيارية
```bash
npm run keystore                 # مفتاح توقيع جديد (يُفضّل عدم تغييره بعد النشر)
python3 scripts/make_icons.py    # يحتاج: pip install Pillow
```

## 4) اللعب مع الأصدقاء (محلياً / واي فاي / إنترنت)

### أ) على جهاز واحد (Pass & Play)
`مباراة جديدة` ← اختر عدد اللاعبين وحدّد كل مقعد «👤 إنسان» ← ابدأ. عند التوزيع يظهر **«سلّم الجهاز إلى …»** فيرى كل لاعب أوراقه سراً، ويتكرر التسليم عند كل دور لضمان الخصوصية.

### ب) شبكة محلية / واي فاي
1. على حاسوب متصل بنفس الواي فاي شغّل: `node server/server.mjs` (استمع على `0.0.0.0:5173`).
2. اعرف عنوان الحاسوب (`ipconfig` / `ip addr`)، مثلاً `192.168.1.10`.
3. على كل جهاز (أو داخل APK) افتح **الأصدقاء** ← أدخل `ws://192.168.1.10:5173/ws` ← **اتصال**.
4. المضيف: **إنشاء غرفة** ويعطي الأصدقاء الرمز (5 أحرف). الضيوف: **انضمام للغرفة**.
5. المضيف يضغط **🚀 بدء المنافسة**. المقاعد تُملأ تلقائياً بالبوتات عند نقص العدد.
6. **💬** للدردشة والإيموجيات والعبارات السريعة، **🎙** لتفعيل المايك (WebRTC مباشر بين الأجهزة؛ الخادم يمرّر الإشارات فقط).

> داخل APK، شاشة «الأصدقاء» هي المكان الوحيد الذي يحتاج إنترنت/واي فاي. بقية اللعبة أوفلاين.

### ج) عبر الإنترنت
شغّل الخادم على VPS خلف Reverse Proxy يدعم WebSocket، واستخدم `wss://your-domain/ws` في حقل العنوان. لا تُخزّن أي بيانات شخصية على الخادم: الغرف في الذاكرة وتُحذف عند خروج آخر لاعب.

### د) البلوتوث
Android WebView لا يوفّر مقابس Bluetooth RFDI مباشرة؛ استخدم «نقطة اتصال/مشاركة واي فاي عبر البلوتوث» أو أي تether بين الجهازين ثم اتبع خطوات (ب). كل خيارات المباراة تبقى متاحة.

### هـ) الأصدقاء والدعوات
**الأصدقاء** ← أضف بالاسم أو الرمز ← اقبل الطلبات الواردة ← **`1 ضد 1`** أو **جماعية**. الدعوة تجهّز إعدادات المباراة بعدد المقاعد المطلوب، وإن كنت متصلاً بالخادم تُنشأ غرفة ويعرض رمزها للمشاركة.

## 5) دليل القواعد المختصر (الكامل داخل زر 📜)

| العنصر | القاعدة |
| --- | --- |
| الأوراق | `J` → `Q` → `K` → `البنط` (الأقوى) |
| قوة اليد | **الكثرة أولاً**: رباعية > ثلاثية > زوجان > زوج > متفرقة، ثم الرتبة ثم الكيكرز |
| مثال حاسم | `J J J J` تهزم `بنط بنط Q Q` |
| الرزم | 2–4 لاعبين: رزمة · 5–8: رزمتان · 9–10: ثلاث رزم (16 ورقة/رزمة) |
| السوق | الجولة الأولى تبدأ بلاعب عشوائي ثم بالترتيب · **لا حد أدنى للرفع** · التمويه مسموح |
| المشرّف | صاحب أعلى مبلغ دخول · يختار «الكل مثبت» أو «عرض الانسحاب والتفاوض» |
| التفاوض | قبول / رفض / تفاوض بمبلغ / إصرار على الكشف · 10، 15، 20، 30 ثانية أو مفتوح |
| المنسحب | لا يُعطى عرضه إلا إن فاز المشرّف (ويُخصم من المشرّف)؛ إن خسر المشرّف فلا ربح ولا خسارة |
| التسوية | الخاسر يخسر مبلغ دخوله، والفائز يربح مبلغ دخوله **فقط** |
| مثال | 50,000 للجميع؛ صالح 5,000 فاز، علي 20,000، أحمد 10,000 ⇒ صالح 55,000 · علي 30,000 · أحمد 40,000 |
| الرحمة | 5,000 مرة واحدة فقط عند نفاد الرصيد |
| الإيقاف | بعد استنفاد الرحمة: 3 جولات كاملة بلا أوراق ولا مشاركة |
| التعادل التام | يُحسم تلقائياً لصالح أعلى مبلغ دخول ثم المقعد الأسبق |

## 6) استكشاف الأخطاء

| العَرَض | الحل |
| --- | --- |
| «تعذّر الاتصال بالخادم» | تأكد من `node server/server.mjs`، ومن أن الجهازين على نفس الشبكة، ومن جدار الحماية للمنفذ 5173 |
| «المتصفح لا يدعم التقاط الصوت» | افتح الغرفة عبر `http(s)` على منفذ الخادم، وامنح إذن المايك؛ الصوت يعتمد على WebRTC |
| «لم يُفتح المايك» داخل APK | امنح إذن `RECORD_AUDIO` من إعدادات أندرويد ← التطبيقات ← تجارة ← الأذونات |
| لا صوت للمؤثرات | اضغط أي زر مرة واحدة (الصوت يُفعّل بعد أول لمسة)، ثم تحقق من `الإعدادات ← المؤثرات الصوتية` |
| رفض التحديث فوق نسخة قديمة | أبقِ `android/release.p12` كما هو؛ تغييره يغيّر بصمة التوقيع |
| الشاشة مزدحمة بـ 10 لاعبين | اضغط زر **▦** أعلى الطاولة للتبديل إلى «قائمة واضحة» |

## 7) الخصوصية والأمان
* لا يوجد أي طلب شبكي داخل APK إلا عند فتح غرفة أونلاين يدوياً.
* أوراق الخصوم تُخفى على مستوى المحرك قبل الإرسال للعملاء (`maskFor`)، ولا تُكشف إلا في المفارشة.
* الخادم لا يسجّل الدردشة ولا يحتفظ بالغرف بعد انتهائها.
* المفتاح المُرفق تجريبي عام: **استبدله بمفتاح خاص قبل النشر على متجر**.
