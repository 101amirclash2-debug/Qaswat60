# نموذج الأمان في قسورة | QASWARA

قسورة يملك **يداً تنفيذية على هاتفك**، لذلك بُني على افتراض أن العقل السحابي قد يُخدَع (Prompt Injection) أو قد يخطئ. الدفاعات متعددة الطبقات، ولا تعتمد على حسن نية النموذج.

## طبقات الدفاع

1. **الواجهة (قبل الإرسال)**
   - درع الأسرار `web/js/privacy.js`: ١٠ أنماط (مفاتيح OpenAI/Groq/Gemini/Anthropic/OpenRouter، GitHub، Slack، AWS، مفاتيح خاصة، JWT، رأس Bearer) → تُستبدل قبل مغادرة الجهاز.
   - مفتاح الإنترنت: إغلاقه يمنع أي طلب شبكي فوراً (`assertInternet`).
   - تقييم خطر محلي (`web/js/safety.js`) + نافذة تأكيد تُظهر الأمر وتصنيفه وأسبابه.

2. **الجسر (السلطة النهائية)**
   - **رمز إلزامي** على كل مسار حساس بمقارنة ثابتة الزمن (`secrets.compare_digest`)، ويُرفض الطلب برمز 401.
   - **قائمة منع** للأوامر المدمّرة في `policy.py`: حذف جذري، `mkfs`، `dd` على أقسام، fork bomb، `reboot`، تعديل `/system`، قتل عملية الجسر، تنزيل وتشغيل سكربت مباشرة، إلخ.
   - **allowlist للحزم**: لا `pkg install` أو `pip install` حرّ؛ فقط حزم معروفة في `PKG_ALLOWLIST` / `PIP_ALLOWLIST` (يمكن توسيعها واعياً).
   - **تقييد المسارات** عبر `safe_join` (منع `..` والمسارات المطلقة)، و**مساحة عمل واحدة** فقط.
   - **حدود**: جسم ٤ MB، ملف ٨ MB، مخرجات ٢٠٠ KB، مهل 1–600 ثانية، ٩٠ تنفيذاً/دقيقة، حدّان متزامنان، وقتل مجموعة العمليات عند التجاوز.
   - **تنظيف البيئة** (`scrub_env`) حتى لا تتسرب أسرار الجلسة إلى أوامر النموذج.
   - **تحقق المدخلات**: أرقام الهاتف (`validate_phone_number`)، لغات التنفيذ، أنواع المستندات، أنواع الوسائط.
   - **CORS مغلق** بقائمة أصول مسموحة، و`/health` فقط عام. الملفات الثابتة بلا رمز لأنها الواجهة نفسها.

3. **الوكيل**
   - كل أمر يمرّ ببوابة قرار: `locked` (منع) / `confirm` (سؤال) / `auto` (تنفيذ مع بقاء قائمة المنع).
   - الأوامر عالية الخطورة **تُسأل دائماً** حتى في الوضع التلقائي.
   - لا يدّعي نجاحاً بلا `OBSERVATION` من الجسر؛ الفشل يُعاد بخطوات مختلفة ثم يُشرح العائق بدقة.
   - الإجراءات الخارجية (مكالمة، SMS، واتساب، تثبيت حزمة) لها بوابة تأكيد مستقلة.

## ما لا يفعله قسورة

- لا يرفع أي شيء إلى سحابة خاصة به: لا خادم وسيط، لا تحليلات، لا تتبّع.
- لا يخزّن مفتاح API في الجسر: يبقى في `localStorage` على الجهاز فقط.
- لا ينفّذ أوامر من شبكة خارجية: الجسر يستمع على `127.0.0.1` افتراضياً.
- لا يفتح ملفات خارج مساحة العمل، ولا يلمس `/system` أو `/data`.

## صلاحيات الهاتف (Shizuku / Termux:API)

| القدرة | ما تحتاجه |
|--------|-----------|
| التقاط الشاشة | Shizuku + `rish` (أو root) — وإلا يعرض الجسر البديل (مشاركة الشاشة/الكاميرا) |
| جهات الاتصال / المكالمات / SMS | `pkg install termux-api` + تطبيق Termux:API + منح الصلاحيات |
| OCR | `pkg install tesseract` |
| PDF نصي | `pkg install poppler` أو `pip install pypdf` |
| PDF إنشاء | `pip install reportlab` |
| أغاني MP3 / فيديو | `pkg install ffmpeg` (+ `espeak-ng` للغناء) |
| بناء APK | JDK 17 + Android SDK (aapt2/d8/apksigner) — عادةً على حاسوب، والـ CI يبنيه تلقائياً |
